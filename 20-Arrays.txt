//!Arrays
--> Array is a special object used to store multiple values in a single variable.
--> Arrays can store different datatypes
--> Arrays are mutable
--> Arrays are dynamic in size
//*Example:
let arr = [10, 20, 30];
let data = ["Rahul", 25, true, null];

//!Ways to Create Arrays
//*1) Using Array Literal
let fruits = ["Apple", "Mango", "Orange"];
console.log(fruits) //['Apple', 'Mango', 'Orange']
console.log(typeof fruits) //object

//*2) Using Array Constructor
let nums = new Array(10, 20, 30);
console.log(nums) //[10,20,30]
console.log(typeof nums) //object

//!Accessing Elements in Arrays
-->Using Indexing
let colors = ["Red", "Blue", "Green"];
console.log(colors[0]); //Red
console.log(colors[1]); //Blue
console.log(colors[10]); //undefined
console.log(colors[-1]); //undefined

//*Note:
--> Array indexing starts from 0.
--> colors[0] means first element.
--> If index does not exist, JavaScript returns undefined.
--> JavaScript arrays DO NOT support negative indexing using [] returns undefined.

//!Length Property:
--> length returns total number of elements
let arr = ["Html","Css","Js"];
console.log(arr.length); //3
console.log(arr[arr.length - 1]); //Js
console.log(arr[arr.length - 2]); //Css
Note:
-->length - 1 always gives last index.

//!Arrays are mutable (Values can be changed after creation)
let fruits = ["Apple", "Mango"];
fruits[1] = "Orange";
console.log(fruits); //["Apple", "Orange"]

//!Methods for Adding Elements

//*1)push()
--> Adds element at end of an array
let arr = [10, 20];
arr.push(30);
console.log(arr); //[10, 20, 30]

//*2)unshift()
--> Adds element at beginning of an array
let arr = [20, 30];
arr.unshift(10);
console.log(arr); //[10, 20, 30]

//!Methods for Removing Elements

//*1)pop()
--> Removes last element from an array
let arr = [10, 20, 30];
arr.pop();
console.log(arr); //[10, 20]

//*2)shift()
--> Removes first element from an array
let arr = [10, 20, 30];
arr.shift();
console.log(arr); //[20, 30]

# 9) splice()

## Definition

--> Used to add, remove, or replace elements

## Syntax

```js
array.splice(start, deleteCount, items)
```

---

## Removing Elements

```js
let arr = [10, 20, 30, 40];

arr.splice(1, 2);

console.log(arr);
```

Output:

```js
[10, 40]
```

---

## Adding Elements

```js
let arr = [10, 40];

arr.splice(1, 0, 20, 30);

console.log(arr);
```

Output:

```js
[10, 20, 30, 40]
```

---

## Replacing Elements

```js
let arr = [10, 20, 30];

arr.splice(1, 1, 100);

console.log(arr);
```

Output:

```js
[10, 100, 30]
```

---

## Definition

# forEach()

## Definition

--> Used for iteration
--> Does not return new array

```js

  console.log(val);
```

# map()

## Definition

--> Returns new transformed array

```js

```

```js

```

---

# filter()

## Definition

--> Returns filtered array

```js
let nums = [10, 20, 30, 40];

let result = nums.filter((val) => val > 20);

console.log(result);
```

Output:


# reduce()

## Definition

--> Reduces array to single value

# 21) Important Interview Questions

# Difference Between slice() and splice()

| slice()                        | splice()                |
| ------------------------------ | ----------------------- |
| Does not modify original array | Modifies original array |
| Returns portion of array       | Adds/removes/replaces   |
| Non-destructive                | Destructive             |

---

# Difference Between map() and forEach()

| map()                   | forEach()             |
| ----------------------- | --------------------- |
| Returns new array       | Does not return array |
| Used for transformation | Used for iteration    |

---

# Difference Between filter() and find()

| filter()                      | find()                         |
| ----------------------------- | ------------------------------ |
| Returns all matching elements | Returns first matching element |
| Returns array                 | Returns single value           |

---

# Difference Between some() and every()

| some()             | every()             |
| ------------------ | ------------------- |
| One condition true | All conditions true |
| OR logic           | AND logic           |

---
