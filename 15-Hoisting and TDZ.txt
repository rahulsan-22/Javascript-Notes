HOISTING:
--> Hoisting is JavaScript's default behavior of moving declarations to the top of their scope before code execution.
--> In JavaScript, variables and functions are processed first before executing the code line by line.
--> Because of hoisting, we can sometimes use variables or functions before they are declared.

Variable Hoisting
1) Hoisting with var
--> Variables declared using var are hoisted and initialized with undefined.
Example:
console.log(a)
var a = 10

How JavaScript sees it internally:
var a
console.log(a)
a = 10
Output:
undefined

Explanation:
--> The variable declaration var a is moved to the top.
--> But the value assignment = 10 stays in the same place.
--> Therefore before assignment, the value becomes undefined.

2) Hoisting with let
--> Variables declared using let are hoisted.
--> But they are NOT initialized immediately.
--> Accessing them before declaration gives an error.
Example:
console.log(a)
let a = 10

Output:
ReferenceError

Explanation:
--> let variables stay inside a special phase called Temporal Dead Zone (TDZ) until the declaration line is reached.

3) Hoisting with const
--> const is also hoisted.
--> But like let, it stays inside Temporal Dead Zone.

Example:
console.log(pi)
const pi = 3.14

Output:
ReferenceError

Function Hoisting:
1) Function Declaration Hoisting
--> Function Declarations are completely hoisted.
--> We can call the function before declaration.

Example:
greet()
function greet(){
   console.log("Good Morning")
}

Output:
Good Morning

Explanation:
--> Entire function definition moves to the top.
Internally:
function greet(){
   console.log("Good Morning")
}
greet()

2) Function Expression Hoisting
--> Function Expressions behave according to the variable keyword used.

Function Expression using var
Example:
hello()
var hello = function(){
   console.log("Hello")
}

Output:
TypeError

Explanation:
--> hello becomes undefined.
--> undefined() cannot be executed as a function.

Internally:
var hello
hello()
hello = function(){
   console.log("Hello")
}

Function Expression using let
Example:
hello()
let hello = function(){
   console.log("Hello")
}

Output:
ReferenceError

Arrow Function Hoisting
Example:
sum()
let sum = ()=>{
   console.log("Arrow Function")
}
Output:
ReferenceError

Explanation:
--> Arrow Functions stored inside variables follow variable hoisting rules.

TEMPORAL DEAD ZONE (TDZ)
--> The time period between variable creation and variable initialization is called Temporal Dead Zone (TDZ).
--> During this period, variables declared with let and const cannot be accessed.
