//!Keyfeatures of Javascript:

//!i)Interpreted:
-->Runs line by line, no compilation needed and runs directly in the browser

//!ii)Dynamic Typing:
-->No need to declare variable type
Ex:let data = "Hello";
       data = 100;  // Allowed

//!iii)Event-Driven Programming:
-->Code runs based on user actions
Ex:<button ondblclick="alert('Welcome to JavaScript')">Click</button>

//!iv)Synchronous and Asynchronous Behavior:
Synchronous:
-->Code runs line by line
Ex:console.log("1");
   console.log("2");
   console.log("3");
Asynchronous:
-->Some tasks run later without stopping main execution.
Ex:console.log("1");
   setTimeout(() => {
     console.log("2");
   }, 2000);
   console.log("3");

//!v)Platform Independent:
-->Runs everywhere in all operating systems and inside browser and on server (Node.js)

//!Note:

//!Scripting Language vs Programming Language
-->A scripting language is used to automate tasks and usually runs inside another environment (like a browser) where as A programming language is used to build complete applications/software.
-->JavaScript is primarily a Scripting Language but it is also considered a full-fledged programming language (because of Node.js)
