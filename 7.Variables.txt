Variables:
-->A variable is a container used to store data.
   Ex: let name = "Rahul";
       name → variable name 
       "Rahul" → value inside the variable

Declaration vs Initialization in JavaScript:
-->Declaration means creating a variable (reserving memory)
   Ex: let name;
-->Initialization means assigning a value to a variable
   Ex: name = "Rahul";
-->Declaration + Initialization:
   Ex: let name = "Rahul";

How to Declare Variables?
-->In JavaScript, we use 3 keywords:
i)var (Old way)
  var age = 25;
ii)let (Modern & recommended)
   let age = 25;
iii)const (Constant value)
   const pi = 3.14;
