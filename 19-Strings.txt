STRINGS:
--> A String is a sequence of characters used to represent text in JavaScript.
--> Strings are immutable in JavaScript (original string cannot be changed).
Examples:
let name = "Rahul";
let city = 'Hyderabad';
let message = `Welcome`;

Ways to Create Strings:

1) Using Single Quotes
let str1 = 'Something'
console.log(str1) //Something
console.log(typeof str1) //string

2) Using Double Quotes
let str2 = "Breakfast"
console.log(str2) //Breakfast
console.log(typeof str2) //string

3) Using Template Literals (Backticks)
--> Used for interpolation and multi-line strings.
Example:
let str3 = `Pavan`
console.log(`My name is ${str3} and my age is ${20 + 5 + 1}`)
console.log(`My 
name 
is 
Pavan`)
console.log(str3) //Pavan
console.log(typeof str3) //string
Note:
--> ${} is called interpolation.
--> It allows inserting variables or expressions inside strings..

Accessing Characters in String:
Using Index:
let subject = "JAVASCRIPT"
console.log(subject[0]) //J
console.log(subject[4]) //S
console.log(subject[10]) //undefined
console.log(subject[-1]) //undefined

Note:
--> String indexing starts from 0.
--> str[0] means first character.
--> If index does not exist, JavaScript returns undefined.
--> JavaScript strings DO NOT support negative indexing using [] returns undefined.

Length Property:
--> length returns total number of characters including spaces.
let str = "JavaScript";
console.log(str.length); //10
console.log(str[str.length - 1]); //t
console.log(str[str.length - 2]); //p
Note:
-->length - 1 always gives last index.

BUILT-IN METHODS:

1) toUpperCase()
--> Converts string into uppercase.

2) toLowerCase()
--> Converts string into lowercase.

3) trim()
--> Removes spaces from beginning and ending.
Note:
--> Does not remove spaces between words.

4) at(index)
--> Returns character at specified index.
--> Supports negative indexing.

5) slice(startIndex, endIndex)
--> Extracts part of string.
--> Supports Negative Indexing: values start from end.
--> If StartIndex > EndIndex returns empty string.
Note:
--> Start index included whereas End index excluded.
--> If only Start Index specified extracts from that start index till end.
--> Original string does not change.

6) substring(startIndex, endIndex)
--> Similar to slice() but does not support negative indexing.
--> Negative index values become 0.
--> If StartIndex > EndIndex swaps values.

7) includes(searchValue, startIndex)
--> Checks whether substring exists.
--> Returns boolean value i.e true if exists and false if not exists

8) indexOf(searchValue, startIndex)
--> Returns first occurrence index.
--> If value not found returns -1.

9) replace(oldValue, newValue)
--> Replace Only First Occurrence.
Note:
--> To replace all occurrences use replaceAll().

10) split(separator, limit)
--> Converts string into array by splitting it based on the separator.

11) startsWith(searchValue, startIndex)
--> Checks whether string starts with specified value.

12) endsWith(searchValue, length)
--> Checks whether string ends with specified value.

Note:
--> String methods are case-sensitive.
--> [] does not support negative indexing.
