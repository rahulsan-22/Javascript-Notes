ARRAYS:
--> Arrays are ordered collections used to store multiple values in a single variable.
--> Arrays in JavaScript are dynamic and can store mixed data types.
--> Arrays are mutable in JavaScript (values can be changed).
--> Arrays use zero-based indexing.
--> Arrays are special types of objects in JavaScript.

Examples:
let arr = [1, 2, 3];
let names = ["Rahul", "Virat"];
let mixed = [10, "Hello", true];

--------------------------------------------------

PART 1: INTRODUCTION TO ARRAYS

Ways to Create Arrays:

1) Using Array Literal (Most Common)
let arr = [1, 2, 3];
console.log(arr);

Output:
[1, 2, 3]

--------------------------------------------------

2) Using Array Constructor
let arr = new Array(1, 2, 3);
console.log(arr);

Output:
[1, 2, 3]

--------------------------------------------------

3) Creating Empty Array
let arr = [];
console.log(arr);

Output:
[]

--------------------------------------------------

Accessing Array Elements:

--> Arrays use index positions.
--> Index starts from 0.

let colors = ["Red", "Blue", "Green"];

console.log(colors[0]);
console.log(colors[1]);

Output:
Red
Blue

--------------------------------------------------

Accessing Last Element:

let arr = [10, 20, 30];

console.log(arr[arr.length - 1]);

Output:
30

--------------------------------------------------

Updating Array Values:

let arr = [10, 20, 30];

arr[1] = 100;

console.log(arr);

Output:
[10, 100, 30]

--------------------------------------------------

length Property:

--> Returns total number of elements in the array.

let arr = [1, 2, 3, 4];

console.log(arr.length);

Output:
4

--------------------------------------------------

Important Notes About Indexing:

1) Accessing Non-Existing Index

let arr = [10, 20];

console.log(arr[5]);

Output:
undefined

--------------------------------------------------

2) Negative Indexing

let arr = [10, 20, 30];

console.log(arr[-1]);

Output:
undefined

Note:
--> JavaScript arrays do NOT support negative indexing directly.

Use:
arr[arr.length - 1]

OR

arr.at(-1)

--------------------------------------------------

3) Changing length Property

let arr = [1, 2, 3, 4];

arr.length = 2;

console.log(arr);

Output:
[1, 2]

Note:
--> Reducing length removes elements permanently.

--------------------------------------------------

Basic Important Methods:

at()

--> Returns element at specified index.
--> Supports negative indexing.
--> Immutable Method.

Syntax:
array.at(index)

Example:
let arr = [10, 20, 30];

console.log(arr.at(1));
console.log(arr.at(-1));

Output:
20
30

--------------------------------------------------

toString()

--> Converts array into string.
--> Immutable Method.

Syntax:
array.toString()

Example:
let arr = [1, 2, 3];

console.log(arr.toString());

Output:
"1,2,3"

==================================================
PART 2: ARRAY MANIPULATION METHODS
==================================================

push()

--> Adds element(s) at the end of array.
--> Mutable Method.

Syntax:
array.push(value)
array.push(v1, v2, v3)

Return Value:
--> Returns new length of array.

Example:
let arr = [1, 2];

arr.push(3);

console.log(arr);

Output:
[1, 2, 3]

--------------------------------------------------

pop()

--> Removes last element from array.
--> Mutable Method.

Syntax:
array.pop()

Return Value:
--> Removed element.

Example:
let arr = [1, 2, 3];

let removed = arr.pop();

console.log(removed);
console.log(arr);

Output:
3
[1, 2]

--------------------------------------------------

shift()

--> Removes first element from array.
--> Mutable Method.

Syntax:
array.shift()

Return Value:
--> Removed element.

Example:
let arr = [10, 20, 30];

arr.shift();

console.log(arr);

Output:
[20, 30]

--------------------------------------------------

unshift()

--> Adds element(s) at beginning of array.
--> Mutable Method.

Syntax:
array.unshift(value)

Return Value:
--> Returns new length.

Example:
let arr = [20, 30];

arr.unshift(10);

console.log(arr);

Output:
[10, 20, 30]

--------------------------------------------------

slice()

--> Extracts portion of array.
--> Original array does NOT change.
--> Immutable Method.

Syntax:
array.slice(start)
array.slice(start, end)

Note:
--> End index is excluded.

Example:
let arr = [10, 20, 30, 40];

console.log(arr.slice(1, 3));
console.log(arr);

Output:
[20, 30]
[10, 20, 30, 40]

--------------------------------------------------

slice() with Negative Index

let arr = [10, 20, 30, 40];

console.log(arr.slice(-2));

Output:
[30, 40]

--------------------------------------------------

splice()

--> Adds, removes, or replaces elements.
--> Mutable Method.

Syntax:
array.splice(start, deleteCount)
array.splice(start, deleteCount, item1, item2)

Return Value:
--> Returns removed elements array.

Removing Elements:

let arr = [10, 20, 30, 40];

arr.splice(1, 2);

console.log(arr);

Output:
[10, 40]

--------------------------------------------------

Adding Elements:

let arr = [10, 40];

arr.splice(1, 0, 20, 30);

console.log(arr);

Output:
[10, 20, 30, 40]

--------------------------------------------------

Replacing Elements:

let arr = [10, 20, 30];

arr.splice(1, 1, 100);

console.log(arr);

Output:
[10, 100, 30]

--------------------------------------------------

concat()

--> Combines arrays.
--> Immutable Method.

Syntax:
array.concat(arr2)

Example:
let a = [1, 2];
let b = [3, 4];

console.log(a.concat(b));

Output:
[1, 2, 3, 4]

==================================================
PART 3: SEARCHING & CHECKING METHODS
==================================================

includes()

--> Checks whether value exists.
--> Returns true or false.
--> Immutable Method.

Syntax:
array.includes(value)

Example:
let arr = [10, 20, 30];

console.log(arr.includes(20));

Output:
true

--------------------------------------------------

indexOf()

--> Returns first matching index.
--> Returns -1 if not found.
--> Immutable Method.

Syntax:
array.indexOf(value)

Example:
let arr = [10, 20, 30];

console.log(arr.indexOf(20));
console.log(arr.indexOf(100));

Output:
1
-1

--------------------------------------------------

lastIndexOf()

--> Returns last occurrence index.
--> Immutable Method.

Example:
let arr = [10, 20, 10, 30];

console.log(arr.lastIndexOf(10));

Output:
2

--------------------------------------------------

find()

--> Returns first matching element.
--> Immutable Method.

Syntax:
array.find(callback)

Example:
let arr = [5, 10, 15];

let result = arr.find(num => num > 8);

console.log(result);

Output:
10

--------------------------------------------------

findIndex()

--> Returns index of first matching element.
--> Immutable Method.

Example:
let arr = [5, 10, 15];

console.log(arr.findIndex(num => num > 8));

Output:
1

--------------------------------------------------

some()

--> Returns true if ANY element satisfies condition.
--> Immutable Method.

Example:
let arr = [1, 3, 5, 8];

console.log(arr.some(num => num % 2 === 0));

Output:
true

--------------------------------------------------

every()

--> Returns true if ALL elements satisfy condition.
--> Immutable Method.

Example:
let arr = [2, 4, 6];

console.log(arr.every(num => num % 2 === 0));

Output:
true

==================================================
PART 4: HIGHER ORDER ARRAY METHODS
==================================================

Callback Function:

--> A callback function is a function passed as argument to another function.

Example:
arr.map(function(item){
   return item * 2;
})

--------------------------------------------------

Callback Parameters:

Most higher order methods provide:
(element, index, array)

Example:
arr.map((element, index, array) => {})

--------------------------------------------------

forEach()

--> Used for iteration only.
--> Does NOT return new array.
--> Immutable Method.

Syntax:
array.forEach(callback)

Example:
let arr = [1, 2, 3];

arr.forEach(num => {
   console.log(num * 2);
});

Output:
2
4
6

Important Interview Note:
--> forEach() always returns undefined.

--------------------------------------------------

map()

--> Transforms each element and returns new array.
--> Immutable Method.

Syntax:
array.map(callback)

Example:
let prices = [100, 200, 300];

let updated = prices.map(price => price + 10);

console.log(updated);

Output:
[110, 210, 310]

Important Interview Note:
--> map() MUST return value from callback.

Wrong:
arr.map(num => {
   num * 2;
})

Correct:
arr.map(num => {
   return num * 2;
})

--------------------------------------------------

filter()

--> Returns elements satisfying condition.
--> Immutable Method.

Syntax:
array.filter(callback)

Example:
let nums = [1, 2, 3, 4, 5];

let even = nums.filter(num => num % 2 === 0);

console.log(even);

Output:
[2, 4]

Important Note:
--> filter() always returns array.

--------------------------------------------------

reduce()

--> Reduces array into single value.
--> Immutable Method.

Syntax:
array.reduce(callback, initialValue)

Callback Parameters:
(accumulator, currentValue)

Example:
let nums = [1, 2, 3, 4];

let total = nums.reduce((sum, num) => {
   return sum + num;
}, 0);

console.log(total);

Output:
10

--------------------------------------------------

Real World Example of reduce()

let cart = [
   { price: 100 },
   { price: 200 },
   { price: 300 }
];

let total = cart.reduce((sum, item) => {
   return sum + item.price;
}, 0);

console.log(total);

Output:
600

--------------------------------------------------

Common Interview Mistakes in Higher Order Methods:

1) Forgetting return in map()

2) Using map() instead of forEach() when no new array needed

3) Forgetting initial value in reduce()

==================================================
PART 5: ARRAY ITERATION & CONVERSION METHODS
==================================================

join()

--> Converts array into string.
--> Immutable Method.

Syntax:
array.join(separator)

Example:
let arr = ["HTML", "CSS", "JS"];

console.log(arr.join("-"));

Output:
HTML-CSS-JS

--------------------------------------------------

split()

--> Converts string into array.
--> String Method.

Syntax:
string.split(separator)

Example:
let str = "HTML,CSS,JS";

console.log(str.split(","));

Output:
["HTML", "CSS", "JS"]

--------------------------------------------------

flat()

--> Flattens nested arrays.
--> Immutable Method.

Syntax:
array.flat(depth)

Example:
let arr = [1, [2, 3], [4, [5]]];

console.log(arr.flat());

Output:
[1, 2, 3, 4, [5]]

--------------------------------------------------

flatMap()

--> Performs map() then flat().
--> Immutable Method.

Example:
let arr = ["hello world", "js array"];

let result = arr.flatMap(str => str.split(" "));

console.log(result);

Output:
["hello", "world", "js", "array"]

--------------------------------------------------

Array.isArray()

--> Checks whether value is array or not.

Syntax:
Array.isArray(value)

Example:
console.log(Array.isArray([1,2]));
console.log(Array.isArray("Hello"));

Output:
true
false

--------------------------------------------------

Array.from()

--> Converts iterable or array-like object into array.

Example:
let str = "HELLO";

console.log(Array.from(str));

Output:
["H", "E", "L", "L", "O"]

PART 6: IMPORTANT INTERVIEW CONCEPTS RELATED TO ARRAYS
==================================================

Shallow Copy

--> Copies only first level.
--> Nested objects still share reference.

Example:
let arr1 = [[1], [2]];

let arr2 = [...arr1];

arr2[0][0] = 100;

console.log(arr1);

Output:
[[100], [2]]

--------------------------------------------------

Spread Operator (...)

--> Expands elements.

Example:
let arr1 = [1, 2];
let arr2 = [...arr1, 3];

console.log(arr2);

Output:
[1, 2, 3]

--------------------------------------------------

Array Destructuring

--> Extracts values from array into variables.

Example:
let arr = [10, 20, 30];

let [a, b] = arr;

console.log(a);
console.log(b);

Output:
10
20

--------------------------------------------------

Difference Between slice() and splice()

| Feature | slice() | splice() |
|----------|----------|-----------|
| Original Array Changes | No | Yes |
| Mutable/Immutable | Immutable | Mutable |
| Purpose | Extract Elements | Add/Remove/Replace |
| Return Value | New Array | Removed Elements |

--------------------------------------------------

Difference Between map() and forEach()

| Feature | map() | forEach() |
|----------|----------|-----------|
| Returns New Array | Yes | No |
| Return Value | New Array | undefined |
| Method Type | Transformation | Iteration |
| Chainable | Yes | No |

--------------------------------------------------

Difference Between find() and filter()

| Feature | find() | filter() |
|----------|----------|-----------|
| Return Type | Single Element | Array |
| First Match Only | Yes | No |
| If Not Found | undefined | [] |

--------------------------------------------------

Difference Between includes() and indexOf()

| Feature | includes() | indexOf() |
|----------|-------------|-----------|
| Return Type | true/false | index |
| Not Found Value | false | -1 |
| Purpose | Existence Check | Position Check |

IMPORTANT INTERVIEW NOTES
==================================================

--> Arrays are objects internally in JavaScript.

typeof array returns:
object

Example:
console.log(typeof []);

Output:
object

--------------------------------------------------

--> To properly check array:
Array.isArray(arr)

--------------------------------------------------

--> Arrays can store mixed data types.

Example:
let arr = [1, "Hello", true, null];

--------------------------------------------------

--> const arrays can still be modified.

Example:
const arr = [1, 2];

arr.push(3);

console.log(arr);

Output:
[1, 2, 3]

Note:
--> const prevents reassignment, NOT modification.
